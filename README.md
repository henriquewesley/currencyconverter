# Conversor de Moedas - DevWH

![logo do conversor de moedas](./assets/logo.png)

Um conversor de moedas web simples e intuitivo desenvolvido como um projeto pessoal/de estudo. Permite converter valores entre diferentes moedas, apresentando os resultados de forma clara e atualizada.

## Funcionalidades Principais

* **Seleção de Moedas:** Permite escolher a moeda de origem e a moeda de destino através de menus dropdown.
* **Entrada de Valor:** Campo para o usuário digitar o valor a ser convertido.
* **Conversão Instantânea:** O resultado da conversão é exibido assim que o valor é digitado ou as moedas são selecionadas.
* **Suporte a Diversas Moedas:** Inclui Real (BRL), Dólar (USD), Euro (EUR), Libra (GBP) e Bitcoin (BTC).
* **Interface Amigável:** Design simples e focado na usabilidade.

## Como Começar

Para usar o conversor de moedas localmente:

1.  **Clone o repositório:**
    ```bash
    git clone [https://docs.github.com/articles/referencing-and-citing-content](https://docs.github.com/articles/referencing-and-citing-content)
    ```
2.  **Navegue até a pasta do projeto:**
    ```bash
    cd [nome da pasta do seu repositório]
    ```
3.  **Abra o arquivo `index.html` no seu navegador.**

O conversor será carregado e você poderá começar a utilizá-lo.

## Utilização

1.  Selecione a moeda que você deseja converter no primeiro menu dropdown ("Converter de").
2.  Selecione a moeda para a qual você deseja converter no segundo menu dropdown ("Converter para").
3.  Digite o valor que você deseja converter no campo de entrada.
4.  O valor convertido será exibido automaticamente na seção inferior.

## Estrutura de Arquivos

* `assets/`: Contém as imagens utilizadas no projeto (logo e ícones das moedas).
* `index.html`: A estrutura HTML da página do conversor.
* `styles.css`: Os estilos CSS para a apresentação visual do conversor.
* `scripts.js`: A lógica JavaScript para realizar a conversão de moedas e atualizar a interface.

## Tecnologias Utilizadas

* HTML
* CSS
* JavaScript
* [ExchangeRate-API](https://www.exchangerate-api.com/): Utilizada para obter as taxas de câmbio em tempo real.
